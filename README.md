# React CSV BOM Assignment

This project contains solutions for **two frontend problems**.

---

## Problem 1: CSV Heatmap Table
- CSV file upload
- BOM items with multiple supplier rates
- Heatmap coloring (min = green, max = red)
- Percentage difference from estimated rate
- Column freeze, sort, hide features

---

## Problem 2: BOM Tree Table
- Hierarchical BOM structure
- Expand/collapse categories
- Clean table layout matching assignment UI
- Fixed alignment and column structure

---

## Tech Stack
- React
- JavaScript
- CSS
- React Router

---

## Run Locally
npm install  
npm start
